# QuizCraft


This C++ program is a console-based quiz management system called “QuizCraft”. It allows two types of users—teachers and students—to interact with quizzes.

Teachers can create quizzes and review student answers.
Students can take quizzes and view results.

The program uses file handling (records.txt and studentsAnswer.txt) to store quiz data and student responses, making it persistent even after the program closes.

Main Features
1. Teacher can create quizzes (different question types)
2. Teacher can view and check student answers
3. Student can take quizzes
4. Student can view results (correct/incorrect)
5. Data is saved in files (records.txt, studentsAnswer.txt)
6. Simple login system for teacher and student
7. Menu-driven interface
